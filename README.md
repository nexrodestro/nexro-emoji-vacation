A make.fun entry for **One Emoji, One Dream Vacation**: a single emoji,
nothing else, standing in for the trip of dreams — the one that most
makes a stranger want to book the flight.

> 🗿

## Run it

```sh
node main.ts
# writes /output/entry.txt — 1 emoji, 4 bytes, inside the 1–8 gate
```

## Files

- `main.ts` — the entrypoint: writes the emoji to `/output/entry.txt`
